# استخراج متن فارسی از کتاب‌های اسکن‌شده (OCR دوستونه پزشکی)

برنامه‌ای برای ویندوز که کتاب‌های اسکن‌شدهٔ پزشکی با چیدمان دوستونهٔ فارسی را
به متن ساده (txt) تبدیل می‌کند. کاملاً آفلاین است — هیچ اتصال اینترنت یا سرویس
هوش مصنوعی لازم ندارد؛ تشخیص متن با موتور استاندارد و متن‌باز Tesseract OCR
(نسخهٔ دقیق fas+eng) به‌صورت محلی روی سیستم شما انجام می‌شود.

## نصب و اجرا

۱. فایل `FarsiOCR-Setup.exe` را اجرا کنید و مراحل نصب را طی کنید.
۲. برنامه را از منوی استارت یا میانبر دسکتاپ باز کنید.
۳. فایل‌های PDF کتاب را انتخاب کنید.
۴. پوشهٔ خروجی را مشخص کنید.
۵. با اسلایدرها حاشیهٔ بالا/پایین/چپ/راست را طوری تنظیم کنید که فقط متن اصلی
   صفحه (بدون سربرگ فصل، شمارهٔ صفحه و نوار کناری ناشر) داخل کادر سبز رنگ
   باقی بماند.
۶. روی «شروع تبدیل» بزنید و منتظر بمانید. برای هر PDF یک فایل `.txt` و یک
   پوشهٔ تصاویر (برای جدول‌ها، الگوریتم‌ها و شکل‌ها) در پوشهٔ خروجی ساخته
   می‌شود.

## نحوهٔ کار برنامه

- هر صفحه ابتدا برش داده می‌شود تا سربرگ/پاورقی/نوار کناری حذف شود.
- محل شکاف میان دو ستون به‌صورت خودکار پیدا می‌شود.
- متن هر ستون (راست سپس چپ، مطابق ترتیب خواندن فارسی) به‌صورت یکجا با
  Tesseract خوانده می‌شود تا دقت بالاتر برود.
- هر بخشی که از قانون دوستونی خارج باشد (جدول، الگوریتم/فلوچارت، شکل یا
  نمودار) شناسایی و از متن جدا می‌شود:
  - **جدول**: خطوط جدول یا فاصله‌های منظم ستون‌ها پیدا و به‌صورت جدول متنی
    بازسازی می‌شود.
  - **الگوریتم/فلوچارت**: جعبه‌های رنگی پیدا و متن داخل هرکدام به ترتیب
    تقریبی از بالا به پایین استخراج می‌شود.
  - در هر دو حالت، تصویر اصلی همان بخش هم ذخیره می‌شود تا در صورت نیاز به
    شکل واقعی (فلش‌ها، شاخه‌ها) مراجعه کنید.

## محدودیت‌های شناخته‌شده

تشخیص متن (OCR) — حتی با بهترین موتورهای آفلاین موجود — هرگز ۱۰۰٪ بی‌خطا
نیست، به‌خصوص برای:
- متن‌های مورب/ایتالیک (مثل منابع سؤال‌ها)
- کلمات رنگی یا بسیار کوچک
- بازسازی دقیق فلش‌ها و شاخه‌های فلوچارت به‌صورت متن خالص (به همین دلیل
  تصویر اصلی هم نگه داشته می‌شود)

توصیه می‌شود متن خروجی را مرور و در صورت نیاز اصلاح کنید. با این حال، این
ابزار بخش عمدهٔ کار تایپ را برای شما انجام می‌دهد.

## ساخت نصب‌کنندهٔ ویندوز از سورس (برای توسعه‌دهندگان)

```
pip install -r requirements.txt
pyinstaller --noconfirm --windowed --name FarsiOCR ^
  --add-data "assets/tessdata;assets/tessdata" ^
  --add-data "C:\Program Files\Tesseract-OCR;tesseract_bin" ^
  main.py
"C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\installer.iss
```

نصب‌کنندهٔ نهایی در `installer_output\FarsiOCR-Setup.exe` ساخته می‌شود.
همچنین یک GitHub Actions workflow (`.github/workflows/build-windows.yml`)
همین مراحل را به‌صورت خودکار روی هر push انجام می‌دهد.
