⚕ دستورات افزودن یا ویرایش بیماری · Add / edit a condition

اینجا متن یک بیماری را می‌نویسید، همان لحظه پیش‌نمایش و بررسی خطا می‌بینید، و با یک دکمه آن را در GitHub ذخیره می‌کنید. تا حدود یک دقیقه بعد در سایت دیده می‌شود.

Write a condition below, see a live preview and error check, then save it to GitHub with one button. It appears on the site about a minute later.

راهنمای نوشتن · How to write (cheat sheet) 
@topic  id                   one per file. id = lowercase-letters-and-dashes
cluster: cardiac             must exist in content/clusters.txt
name: English name
name_fa: نام فارسی
source: A | B | AB           which handout the orders come from
keywords: words for search
refs: key1, key2             guideline keys from content/references.md

@guide                       plain Farsi study guide for the condition (blank line = new paragraph,
                             "- " = bullet, "# " = small heading)

@variant  id                 one per order set. A topic can have several
name: ...    level: I | II | III    source: A | B | AB    meta: free text    refs: keys
@scenario                    plain Farsi case that matches this order set
@why                         plain Farsi: what is special about THIS order set
@orders
- one order per line         **bold**   [[other-variant-id|link text]]
-- a sub-heading
- order from one source @A   (@A, @B or @AB shows a small source badge)
- order added from a guideline [^key]   (adds a numbered reference at the bottom)
@branch                      an IF / OTHERWISE box (repeat for more boxes)
if: the condition
- orders when true
else: label for otherwise
- orders when false
go: variant-id, other-id     links to other pages
@branch
title: A box without a condition
- orders
@notes                       Persian notes copied from the source (optional)
- ...
// a line that starts with // is a comment
